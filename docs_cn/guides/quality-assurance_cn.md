# 质量保证

English: [quality assurance](../../docs/guides/quality-assurance.md)

本指南覆盖 Transnet 周边的 Island-port 产品，包括 MySQL、Qdrant、隐私、持久化、反馈、练习和 worker。当前 Transnet 可执行文件只实现适用的 HTTP、提供商容错、schema 校验和脱敏子集。

## 状态

本指南定义拟议的学习功能评估和发布流程；评估工具与数据集尚未在当前分支实现。

## 评估工件

维护版本化、许可明确、可复现的基准集、人工审查记录、对抗性输入集和发布报告。基准不得混入私有学习者内容。

## 多语言查词集

每种启用语言和方言都要有平衡的受审查查询集，包含常见词、词形变化、短语、同形词、拼写错误、罗马化和低置信语言判定。

## 查词指标

评估语言判定、词形还原、词义排序、英语等价表达、证据覆盖、拒答和降级路径，并按语言、等级、内容类型和检索路径报告。

## 关系指标

评估关系类型、方向、词义配对、尺度顺序和来源证据；向量相似度不能替代关系正确性。

## 学习卡评分标准

检查定义、译释、例句、用法、语法、搭配、易错点、词源和来源是否与选定词义一致，且不虚构缺失内容。

## 练习评估

检查可作答性、答案集合、干扰项、提示泄漏、目标词义、语言、方言、级别、评分校准和重复提交安全。

发布评估按语言、方言、级别、内容类型和检索路径切片。调度模拟覆盖时区、夏令时、时钟偏差、并发、重试、迁移、暂停、词义拆分和删除账号。

## 安全与隐私套件

测试跨账号访问、凭据生命周期、CSRF、credentialed CORS、SQL/JSON/Unicode/prompt/检索内容注入，以及日志和 trace 中的查询、上下文、答案、笔记、token 和身份泄漏。验证共享缓存隔离、能力 token 的熵/哈希/过期/重放防护、历史退出/导出/删除和来源移除是否覆盖卡片、向量、缓存、导出物和生成 manifest。

## 可靠性套件

注入 MySQL、向量检索、缓存、模型超时、无效 JSON、限流、过期内容、worker 延迟、outbox 重放和图扩展失败。预期行为包括：模型不可用时返回确定性卡片或可重试错误，向量不可用时继续精确/形态/短语/全文检索，MySQL 不可用时权威读写 fail closed，缓存不可用时在有界并发下继续，模型 JSON 修复一次后再降级，模糊评分返回 `needs_review`，过大图返回排序截断和 cursor，MySQL/Qdrant 漂移触发过滤、告警、校准和重建。

验证 deadline 传播、重试分类、熔断、请求合并、任务租约、死任务重放，以及不重复产生可计费或状态变更工作。

## API 契约套件

每个示例必须通过公开 JSON Schema；OpenAPI 变更不得产生未审查的向后不兼容。cursor、ETag、`If-Match`、幂等、能力和 `Retry-After` 行为必须确定。异步任务最终返回与同步查词相同的学习卡 schema，图边端点必须存在于节点列表，派生边不接受反馈。

## 初始发布门禁

初始发布门禁包括：所有公共示例和 fixture 通过校验；每个启用语言在平衡审查集上达到至少 90% top-1 意图等价准确率和 97% top-3 召回；重大误译低于 1%；语言判定和敏感内容切片达标；显示的词源、用法、发音、CEFR 和频率都有许可来源；图关系类型和词义配对至少 90% 正确；练习至少 95% 可作答且无泄漏；重试不会重复提升掌握度；反馈幂等、可逆并绑定边版本；权限、隐私、删除、降级、负载和注入测试通过。

## 生产监控

监控路由和语言对的请求结果与阶段延迟、检索路径和覆盖率、模型 schema 有效性与成本、图截断与反馈延迟、练习按技能的正确率、来源新鲜度、任务积压、Qdrant 同步和 Island-port 限流结果。生产数据用于发现回归，不会自动变成训练数据；采样私有内容需单独同意、最小化、权限和保留策略。

## 发布报告

每个内容、prompt、模型、ranker、评估器或 scheduler 发布记录输入版本、分片评估、已知限制、隐私/许可/安全签核、容量成本、迁移回滚、监控阈值和负责人。
