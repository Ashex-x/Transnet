# Transnet 交付计划

English: [Transnet delivery plan](../docs/todo.md)

本计划对[英语学习代理设计](transnet_cn.md)的实现排序，描述目标工作而非已实现行为。

## 当前基线

- [x] 回环 HTTP、健康探针、请求限制、请求 ID、优雅停机和脱敏 tracing。
- [x] 翻译提供商路由、容错和结构化词汇查询基础。
- [ ] 产品路由、存储、知识发布、书签学习、评估、排程、写作和语音。

## 阶段 1：意图与响应语义

- [ ] 用有类型语言意图取代字符数产品路由。
- [ ] 实现翻译优先响应和最多两条有理由的提示。
- [ ] 分开翻译维基结果与学习者所有的学习卡。
- [ ] 版本化每个模型角色的 schema、prompt、rubric 和修复/降级行为。

## 阶段 2：规范卡与知识图谱

- [ ] 实现无 Qdrant 仍可用的 MySQL 分词义基础卡。
- [ ] 构建带稠密和稀疏向量的不可变 Qdrant 节点/边集合。
- [ ] 实现确定性 ID、端点校验、证据范围、版本钉住、对账、隔离和回滚。
- [ ] 保持已验证边与探索性向量关联分离。

## 阶段 3：书签与持续学习

- [ ] 只在明确书签后创建完整冻结的学习卡修订。
- [ ] 支持查看、暂停、重排、刷新、删除和待再生成状态。
- [ ] 只保留 30 天内最新 200 个紧凑规范事件，并实现立即清除。
- [ ] 仅从书签和合格历史重建带信心的策略。
- [ ] 独立跟踪各技能，并实现版本化 FSRS 风格排程。

## 阶段 4：练习、写作、文化与语音

- [ ] 实现从识别到独立产出与迁移的练习。
- [ ] 实现保留意义和声音的写作评估以及有语境范围的沟通教练。
- [ ] 实现参考 TTS、录音质量检查、识别、对齐、声学证据与不确定性。
- [ ] 确保独立写作、翻译、查询和语音不会创建持久目标。

## 阶段 5：隐私、可访问性与发布质量

- [ ] 防止原始学习者内容进入策略历史和 Qdrant。
- [ ] 提供书签、卡片、排程、历史、录音、导出和删除控制。
- [ ] 提供图的键盘列表/树等价视图、减少动效和非仅颜色语义。
- [ ] 对所有影响结果的工件版本化，并通过教学、迁移、文化、语音、隐私、注入、降级和回滚门禁。

## 完成标准

- 句子返回翻译优先结果，词汇单位返回分词义翻译维基页。
- 书签是创建持久学习卡和排程目标的唯一事件。
- 无 Qdrant 时基础卡可安全降级，相似度不会成为无支持事实。
- 只提升直接证明的技能，不确定评估不降低掌握度。
- 策略可完全由当前书签和有界历史解释，并可通过控制重置。
- 中英文档、人工合同、机器合同、源注释和测试与行为同步更新。
