# Transnet 交付计划

English: [Transnet delivery plan](../docs/todo.md)

本计划把权威的 [Transnet 设计](transnet_cn.md)转化为有顺序、可验证的交付切片。它追踪仓库现状而非愿景：只有代码、测试与适用合同一致时，项目才可勾选。

状态：实施中。当前可执行文件提供回环地址上的翻译服务和模型驱动的结构化查询。规范 MySQL/Qdrant 落地、关系优先页面组织及领域感知展开仍是目标能力。

## 交付规则

- 产品只聚焦两种体验：连续文本翻译，以及围绕一个已解析词义或领域概念的关系型翻译维基页面。
- 保持无状态边界。实时请求文本、翻译历史、派生向量和中间分析只存在于单次有界请求中，不得成为规范数据或用户数据；单独的已审核 publisher 输入可以成为规范内容。
- 通过类型、端口、适配器、运行时组合、HTTP 行为、可观测性、测试和双语文档交付垂直切片。
- 明确区分当前行为与目标行为。文档中的目标路由或 Schema 不代表当前可执行文件已经启用它。
- 分离 `verified`、`inferred` 与 `exploratory` 关系。只有发布工作流可以创建或修改规范知识。
- 产品语义、合同、配置或发布行为变化时，同步更新中英文文档。

## 已验证基线

- [x] 私有回环 HTTP 进程、请求边界、精确 Origin CORS、请求 ID、健康探针、优雅停机和脱敏结构化 Trace。
- [x] 基于长度的翻译 Provider 路由、有界容错和聚合运行指标。
- [x] 默认可执行文件中的模型驱动结构化词汇查询。
- [x] 规范查询、词义详情、内容发布和有界图读取的库基础与进程内测试适配器；它们并非生产存储组合。
- [x] 翻译、查询、词义详情和有界图读取的目标人工合同与机器合同。
- [ ] 生产 MySQL/Qdrant 适配器、发布与配对激活、关系页面组织，以及完整目标线上语义。

## 里程碑 0：强制聚焦且无状态的边界

- [ ] 从可达服务 API 和可复用公共领域类型中移除学习者画像、历史、收藏词汇、掌握度、日程、练习、训练会话、辅导、图布局、私有反馈、写作评估、语音和发音模块。
- [ ] 移除可能保留查询、上下文、派生向量、模型输出或 Provider 结果的异步查询任务与持久工作路径；查询只在请求生命期内执行。
- [ ] 移除过渡性的用户导向字段；拒绝 Cookie、终端用户凭据、用户或账户标识、私有状态字段及未知字段，且不回显其值。
- [ ] 审计日志、Trace、指标、缓存、队列、错误、Debug 格式和 Provider 遥测，防止请求内容、上下文、中间分析、凭据和调用方身份泄露。
- [ ] 围绕“翻译 + 关系型查询”同步代码注释、测试和人工合同。

退出标准：没有可达路由或可复用公共服务 API 接受产品拥有的状态或暴露范围外学习模块；请求派生内容无法进入持久端口；边界拒绝与非持久化测试通过。

## 里程碑 1：冻结翻译与意图路由

- [ ] 实现共享成功/错误 Envelope、严格未知字段拒绝、语言标签验证、请求元数据及安全状态映射。
- [ ] 实现简单的文本、源语言、目标语言、响应级别与可选最小历史请求，以及判别式单词、短语和段落 `TranslationResult` 响应。
- [ ] 实现版本化请求内 Normalizer，包括 Unicode 规范化、语言感知大小写折叠、空白与标点处理、有意义符号保留和有界派生形式。
- [ ] 在一个翻译入口之后，将高置信单词、术语、习语、短语动词或固定短语路由到词汇组织，并将分句、句子、篇章和歧义短片段路由到连续文本翻译。
- [ ] 对齐 `POST /transnet/v1/translations`：保留含义、语气、术语、语域、段落结构、受保护片段和格式；最多返回两条重要单句提示及一个已标注备选。
- [ ] 为长文或难文添加请求内分块规划和一次性术语台账，不创建翻译记忆。
- [ ] 接受 island-port 控制且无独立项目数上限的翻译 turn 历史，只用于当前语言上下文，并证明其绝不进入日志、缓存、嵌入、队列或持久存储。
- [ ] 构建一个发布固定的超集聚合及确定性 `brief`、`standard` 和 `full` 投影器；即使在较低级别也保留实质不同含义。
- [ ] 在适用时把 Schema、Normalizer、模型、Prompt 与检索版本写入响应元数据。

退出标准：合同与路由测试覆盖词汇单元、技术符号、短语、歧义片段、句子和篇章；翻译评估覆盖忠实度、自然度、术语、结构、语域和提示数量。

## 里程碑 2：构建规范身份与 MySQL 基础卡

- [ ] 为卡片、词义、形式、别名、定义、翻译、发音、形态、例句、用法说明、领域、证据、不可变修订和发布 Manifest 定义迁移与生产适配器。
- [ ] 为已审核单词、短语和有界段落实装规范翻译身份、不可变修订、带源文验证的精确 fingerprint 解析、发布暂存、权利与证据检查及发布成员关系。
- [ ] 按有文档、版本化策略稳定生成卡片、词义、概念根、领域、证据与修订 ID；绝不使用规范化查询字符串作为身份。
- [ ] 在有界屈折、拼写修正、转写和语义候选之前解析精确规范形式与别名。
- [ ] 分离同形异义词、词性、短语整体意义和领域特定词义，并保留组合意义与短语级意义的区别。
- [ ] 返回无需 Qdrant 或 LLM 仍有用的精简、锁定发布版本的基础卡。
- [ ] 实现草稿暂存、冲突与许可检查、隔离、以新修订进行修正、不可变保留、就绪探针、Fixture 和安全失败映射。

退出标准：仅靠 MySQL 可完成精确查询与词义读取；歧义形式返回排序候选或澄清；发布、冲突、证据、隔离和不可变性测试通过。

## 里程碑 3：发布有类型关系模型

- [ ] 定义可扩展节点类型：词义、短语、术语、概念、现象、机理、过程、方程、物理量、材料、仪器、方法、技术、应用、标准、组织、人物、地点、语法模式、搭配、习语、隐喻、误解和领域。
- [ ] 定义关系类型及其方向、逆关系、对称性、传递性、因果性、适用词义与领域、条件、证据要求、置信度、来源和验证规则。
- [ ] 覆盖词汇命名、翻译等价、分类、整体—部分、明确命名的强度、对比、句法、搭配、形态、适用性、文化延伸、术语、领域归属、机理、因果、依赖、实现、应用、测量和标准化。
- [ ] 先构建确定性、不可变 Qdrant 节点集合，再构建边集合；只从已发布内容生成具名跨语言稠密向量和稀疏词法向量。
- [ ] 校验端点存在、发布兼容性、重复有类型边、方向、范围、条件、证据、置信度、验证状态和嵌入元数据。
- [ ] 对账 MySQL 根、Qdrant 哈希与端点覆盖率，然后原子激活或回滚一个兼容发布三件套。

退出标准：投影可从一个规范发布中复现重建；每条已验证关系都有名称、范围、证据和发布版本；局部或不兼容发布无法激活。

## 里程碑 4：实现有界关系检索

- [ ] 实现精确、稀疏、稠密、混合、端点和重排检索，并在限制数量前应用发布、状态、语言、方言、地区、时期、领域、证据和验证过滤。
- [ ] 展开前解析一个规范根，只返回与该根存在明确、有用路径的关系。
- [ ] 支持按目的排序的直接分组及短的证据路径；每个中间步骤都必须有命名关系和独立合格证据。
- [ ] 将任意深度遍历、无限制邻居倾倒、最短路径推断和可变图事务排除在服务合同之外。
- [ ] 在存储、响应、排序与展示中分离规范已验证边、请求内推断综合及探索性向量/模型提案。
- [ ] Qdrant 不可用时返回明确的 MySQL-only 降级卡，不生成替代关系。

退出标准：检索有界、锁定发布、过滤安全，且对一个选定根有用；对抗测试证明相似度绝不建立翻译、同义、层级、因果、共同机理或文化含义。

## 里程碑 5：组织关系型翻译维基页面

- [ ] 在词义解析后添加有界领域评估：`general`、`domain_specific`、`mixed` 或 `uncertain`，以及经校验的候选领域 ID 和简短理由。
- [ ] 在评估前检索已有领域清单与 RAG 覆盖；只有清单成功且提供范围均不适用时才返回 `proposed_new`，不提供 live 创建 endpoint。
- [ ] 发布并补全原子基本事实、领域知识 profile 和第一类语义尺度；LLM bootstrap 只能通过隔离离线候选进入。
- [ ] 将多语言术语与别名解析到共享概念，同时保留首选术语、译名、别名、地区、学科和使用状态。
- [ ] 只排序和分组有用且有支持的内容：含义、术语、分类或程度、对比、配价、搭配、适用性、形态、文化延伸、机理、相邻现象、应用、测量、标准和使用惯例。
- [ ] 使用渐进展开：先基础卡或概念摘要，再高价值直接分组、可选具名短路径，以及视觉分离的探索区。
- [ ] 对 Router、Resolver、领域评估器、Ranker、Composer、Prompt、Schema 和修复策略进行版本化；确定性校验结构、范围、证据标签、简洁度和不确定性。
- [ ] 仅在明确标注时允许请求内生成例句和推断解释；绝不持久化或作为已验证事实展示。
- [ ] 只把结构化关系缺口提案发送到离线审核；实时查询不得将其发布或展示为规范边。

退出标准：通用词、复合表达、歧义技术词义和多语言领域概念都生成精简页面，其分组与路径相关、范围正确、证据透明且可复现。

## 里程碑 6：为聚焦产品设置发布门禁

- [ ] 为路由、翻译、词义/概念解析、领域评估、关系选择、路径有效性、遗漏、编造、术语、语域、文化和 Prompt 注入构建版本化挑战集。
- [ ] 测试关系族语义，包括分类与强度、短语与组件意义、词义适用性、逆向方向、条件有效性及 `verified`/`inferred`/`exploratory` 分离。
- [ ] 注入模型、MySQL、Qdrant、过期发布、局部发布、无效输出、限流、超时和回滚失败，验证安全降级及有界修复。
- [ ] 证明 MySQL、Qdrant、缓存、日志、Trace、指标、队列、备份、Provider 遥测和派生向量均不持久化请求内容。
- [ ] 以格式化、Lint、测试、Rustdoc、合同检查、发布对账、回滚演练和双语文档检查作为发布门禁。

退出标准：用户可翻译连续文本，或通过精简准确的关系深入理解一个选定词义/领域概念，且不会遇到无关图展开或无支持模型断言。

## 完成定义

- 句子或篇章优先翻译；高置信词汇单元获得以一个适用词义或概念为根的关系型页面。
- MySQL 基础卡在没有 Qdrant 时仍有用，图检索不可用时明确降级。
- 每条展示关系都对选定根有用，并按需暴露类型、方向、适用范围、证据状态、置信度和来源。
- `verified`、`inferred` 与 `exploratory` 内容绝不混淆；相似度绝不升级为规范事实。
- 内容发布只以对账后的 MySQL/Qdrant 三件套激活，并通过不可变选择回滚。
- 请求内容、上下文、中间分析、调用方身份或用户状态均不被持久化，也不经可观测性或错误泄露。
- 中英文设计、行为、接口、机器合同、指南、注释和测试与已启用运行时一致。
