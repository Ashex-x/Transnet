# Transnet 服务行为

English: [Transnet service behavior](../../docs/product/service-behavior.md)

本指南描述无状态 Transnet 服务对消费者可见的行为。产品应用拥有自己的用户体验，可在任意工作流中使用这些响应，而不向 Transnet 发送用户数据。

## 翻译

`POST /translate` 接受有界源文本和请求级语言或语域选项，返回自然的目标语言文本，并保留含义、语气、语域和段落结构。服务最多增加两条精简提示，且只在歧义、习语、重要语域选择或文化语境实质影响翻译时增加。

## 词汇与概念查询

`POST /v1/lookups` 将单词、固定词汇短语或专业术语解析为一个选定规范词义或概念。它先呈现精简卡片：规范形式与译名、别名、适用时的词性、定义、发音、形态、例句、领域 ID 和发布元数据。同形异义词、不同词性、短语级含义和领域特定词义保持分离。歧义会返回排序候选或澄清结果；无法高置信视为词汇单元的片段会路由到翻译。

可选 `context` 仅用于当前请求消歧，不会保留。请求语言、方言、语域和详情选项只改变响应呈现。

## 关系与领域探索

规范卡片锚定有界 Qdrant 关系读取。页面提供按用途排序的有类型关系分组、解释、条件、来源、证据状态和发布元数据。对于普通词汇，邻域可包含分类、强度、对比、句法、搭配、语域、形态和文化延伸；对于领域概念，还可包含多语言术语、领域与子领域、机理、前置概念、现象、方程、技术、应用、测量、标准和专业用法惯例。

LLM 将已解析含义分类为 `general`、`domain_specific`、`mixed` 或 `uncertain`，并选择有用的关系分组；规范数据负责验证其候选。已验证关系、基于证据的请求内推断，以及探索性向量或模型关联必须在视觉上保持分离。选定一个根节点可展开一个浅层邻域或有名关系的短路径；Transnet 不把相似链展示为事实路径。

## 内容与安全

相关答案均钉住规范内容发布。MySQL 提供精简规范卡片，Qdrant 提供关系；图检索不可用时服务会明确降级到基础卡。服务绝不存储请求文本、上下文、调用方身份或任何用户相关状态。
