# 英语学习体验

English: [English-learning experience](../../docs/product/learning-experience.md)

## 状态

本文描述由 Island-port 与 Transnet 协调的学习者行为。[系统设计](../transnet_cn.md)定义边界，[Island-port 接口](../interfaces/port_cn.md)定义服务合同。

## 语言行为

学习者选择解释语言、英语方言和大致 CEFR 等级；解释语言可以不同于当前查询语言。基础行为包括：非英语词返回源语言词义和自然英语对应项；英语词进入英语学习词典模式；屈折形式解析到 lemma 但保留原查询形式；短语和习语作为一个词汇单元处理；上下文只重新排序，不删除其他合理词义；拼写错误返回明确的建议而不悄悄替换原文；罗马化可同时显示原脚本；低置信语言识别返回备选或请求选择；敏感词以中性说明和适当警告呈现。

只有具备许可词源、形态支持和母语评估的语言才会启用。增加语言是内容与质量发布，而不只是打开语言代码。

## 核心旅程

### 查词并理解

学习者提交单词或短表达，可附源语言和上下文。Transnet 解析语言、形式、词位、词性和词义，保持同形词分离，并按上下文和学习者相关性排序。结果是带证据和覆盖状态的学习卡；Island-port 可在计算完成后保存选定词义或私有历史。

### 探索相关语言

客户端请求按关系、级别、语言或词性限制的图邻域。学习者可以展开节点、拖动 3D 布局、评价个人有用性或报告事实问题。个人排序立即更新，符合条件的事实报告异步进入社区审查。

### 练习与复习

调度器选择到期词义和薄弱技能，而不只选择最近拼写。学习者对冻结的练习实例提交一次答案；服务端只更新一次掌握度，并把解释链接回词义和证据。

## 学习卡

每个结果先按词条、再按词义分组。“显示全部”表示响应限制内的所有分析；罕见词义使用渐进展示和 cursor 分页。卡片可包含：原始/规范形式、语言、脚本、lemma、形态与拼写建议；英语词头、音节、发音、许可音频和方言；词性、形式和派生关系；定义、译释、领域、CEFR、频率和置信度；语域、方言、内涵、敏感性、可数性、及物性；语法框架与搭配；自然例句；易混词和常见错误；词源；私有学习历史；同义、反义、上下位、词族、关联和尺度关系；练习建议；逐断言证据、来源许可和版本。

每个部分报告 `available`、`partial`、`unavailable`、`disputed`、`not_requested`、`blocked_by_policy` 或 `temporarily_unavailable`。生成例句、简化说明和助记法必须明确标记；缺失字段不得臆造。

## 词义、用法和关系

学习状态和语义关系绑定词义，而不是仅绑定拼写。常见和上下文相关词义优先，少见、过时、技术、地区和冒犯性词义在证据与政策允许时仍可发现。用法说明应是描述性的，并注明来源范围和版本；近义词必须解释不可互换的场景。

关系图包括同义/近义/翻译等价、反义、上下位、整体/部分、易混词、主题关联、屈折/派生/词源关系、搭配和有序尺度。`cool < warm < hot < scorching` 是有上下文的尺度，不是父子层级。3D 图是可选展示；列表或树视图必须提供键盘操作、减弱动画和文本标签。拖动只改变客户端布局，坐标不是词汇证据。

个人有用性反馈与事实准确性反馈分开。`more`/`less`/`reset` 只影响个人排序；准确性可为 `accurate`、`wrong_sense`、`wrong_type`、`too_broad`、`missing_restriction`、`unsupported`、`unsure` 或 `reset`。`unsure` 是弃权，不是反对票；派生尺度边和纯展示边不可直接投票。

## 练习与个性化

练习技能包括意义识别、词义辨析、英语回忆、拼写/形式、搭配、语法、语域选择、近义词对比、自由产出和听力/发音。掌握度按 `(learner, sense, skill)` 记录；识别正确不代表能回忆、变形、搭配或选择合适语域。

优先使用策划题目和确定性模板，异步生成可复用候选。题目冻结目标词义、辅助目标、语言、方言、级别、内容版本、生成器、模型、prompt、规范化、rubric 和评估假设。只在答案提交后展示答案；无把握的自由回答不降低掌握度；反馈要解释词义、语法、搭配或用法差异。

个性化只使用必要输入：解释语言、已知语言、英语水平、方言、目标、可选兴趣、无障碍设置、近期选择和技能掌握度。关闭个性化会恢复共同的证据排序，不删除历史；个性化决定记录版本以便复现。

## 历史、隐私与成功指标

词汇历史是公开来源内容，学习历史是私有用户数据。历史须在知情选择后启用；Island-port 管理保留、匿名查词、删除、导出和账号流程。上下文、查询、答案、笔记和评论不进入日志或共享向量索引；未经单独明确选择，不用于模型训练。

首要产品结果是学习者在未见上下文中延迟回忆并正确使用词义，而不是查词次数或停留时间。辅助指标包括词义选择、卡片覆盖、图到练习转化、可作答性、按技能的掌握度、7/30 天保持率，以及各启用语言和方言的质量平等。
