# Transnet 服务行为

English: [Transnet service behavior](../../docs/product/learning-experience.md)

本指南描述无状态 Transnet 服务对消费者可见的行为。产品应用拥有自己的用户体验，可在任意工作流中使用这些响应，而不向 Transnet 发送用户数据。

## 翻译

`POST /translate` 接受有界源文本和请求级语言或语域选项，返回自然的目标语言文本，并保留含义、语气、语域和段落结构。服务最多增加两条精简提示，且只在歧义、习语、重要语域选择或文化语境实质影响翻译时增加。

## 词汇查询

`POST /v1/lookups` 将单词或固定词汇短语解析为一个或多个规范词义。它先呈现精简卡片：规范形式、词性、定义、翻译、发音、形态、例句、CEFR 元数据、领域 ID 和发布元数据。同形异义词和不同词性保持分离；拼写错误或歧义片段返回明确候选或翻译模式结果。

可选 `context` 仅用于当前请求消歧，不会保留。请求语言、方言、语域和详情选项只改变响应呈现。

## 知识探索

规范卡片链接到有界 Qdrant 图读取。图响应提供有类型关系、解释、证据状态和发布元数据。已验证关系与探索性向量关联分开。选择一个根可扩展一个浅层邻域；Transnet 不把相似链展示为事实路径。

## 内容与安全

相关答案均钉住规范内容发布。MySQL 提供精简规范卡片，Qdrant 提供关系；图检索不可用时服务会明确降级到基础卡。服务绝不存储请求文本、上下文、调用方身份或任何用户相关状态。
