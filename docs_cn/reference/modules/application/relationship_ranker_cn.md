# 关系排序器

English: [Relationship ranker](../../../../docs/reference/modules/application/relationship_ranker.md)

关系排序 application 模块围绕一个选定含义根，按用途排序合格规范关系与明确标注的请求级关系。

状态：目标设计。已有图基础包含相关不变量，但当前可执行文件未组合此目标排序器。

## 职责

排序器接收已补全事实 bundle，只保留适用于选定词义、领域、语言、地区、时期、条件和证据策略的事实。它分组并排序有用关系，但不改变身份、方向、来源、验证状态或证据状态。

分类、部分整体、强度、同义、对比、语法、术语、技术事实和探索性关联保持不同。`is_a` 从子词义指向父类别，`has_subtype` 为其逆关系。语义尺度是独立命名的有序维度，不是分类，也不表示等数值间距。

## 依赖与不变量

对于相同发布、策略版本、根和合格输入，排序结果是确定性的。模型生成解释可协助组织，但不能使候选合格，也不能把 `inferred` 或 `exploratory` 内容转成 `verified`。

每个保留项目都有回到含义根的明确有用路径。相似度只影响候选排序，绝不建立事实。

## 验证

测试应覆盖适用性过滤、稳定排序、证据阈值、逆向方向、分类环、完整合格语义尺度、关系族分离和平局。对抗套件应拒绝把向量接近提升为事实关系类型。
