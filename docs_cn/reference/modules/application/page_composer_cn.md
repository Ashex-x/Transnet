# 关系页面组织器

English: [Relationship page composer](../../../../docs/reference/modules/application/page_composer.md)

页面组织 application 模块在响应级别投影前，把含义专属词汇与领域材料组织成目标超集结果。

状态：目标设计。当前旧结构化查询使用学习专属模型 schema，并非这一共享、发布支撑的组织器。

## 职责

组织器从一个选定词义或领域概念开始，安排精简定义、用法、例句、词汇分组、领域事实、语义尺度、来源和短连接解释。它省略空或支持薄弱的分区，并可按用途重排合格分组。

模型是组织器，不是所有事实的来源。它可在有界结构化输出中总结或连接已提供事实，但不能改变事实身份、方向、适用范围、证据、来源、验证状态或发布。

## 依赖与不变量

模块接收已解析含义和已排序、已补全的关系。它可通过模型 port 调用有界结构化组织操作；确定性代码依据所提供 bundle 检查所有引用。

每个分区始终归属于其含义根。Verified、inferred 与 exploratory 材料保持清楚分离，每条展示连接路径只包含具名且独立合格的步骤。除非已属于规范内容，否则解释与例句均为请求级内容。

## 验证

测试应覆盖多含义、根归属、空分区省略、精简解释、事实引用校验、路径完整性和证据状态分离。无效模型新增、被改变的 ID、无支持断言和跨含义泄漏必须被拒绝或安全省略。
