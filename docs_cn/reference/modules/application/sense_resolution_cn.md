# 词义解析

English: [Sense resolution](../../../../docs/reference/modules/application/sense_resolution.md)

词义解析 application 模块把单词或固定短语映射到发布固定的规范候选，同时保留实质歧义。

状态：基于已有基础的目标编排。仓库已有规范查询、卡片和词义组件，但尚未组合到当前可执行文件的默认翻译路径。

## 职责

模块通过版本化 normalizer 推导有界查询形式，并按证据强度依次排序精确规范、别名、屈折、拼写和语义候选。在存储合同要求时，它比较精确存储的源文本；仅 fingerprint 不构成身份。

含义使用稳定词义 ID 而非规范化字符串标识。当前文本与历史可对候选排序，超集中保留多个实质合理含义。模块绝不因查询而创建卡片、别名或词义。

## 依赖与不变量

解析使用发布固定的结构化数据读取，并且只能使用向量检索提出语义候选。相似度绝不建立翻译等价或词义身份。`C`、`C++`、`C#` 等有意义符号保持不同。

返回的定义、例句和关系必须归属于适用词义。历史可消歧，但不能改写规范身份、事实方向或证据。

## 验证

测试应覆盖 normalizer 版本、精确与别名优先级、屈折、拼写建议、多语言别名、符号、含糊词性、保留多个含义、发布不匹配和降级精确卡片读取。对抗测试应确保语义接近绝不提升为规范匹配。
