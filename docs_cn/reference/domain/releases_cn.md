# 发布与降级

English: [Releases and degradation](../../../docs/reference/domain/releases.md)

本模块负责不可变兼容发布身份与显式降级读取状态。

## 发布三元组

一个活动内容视图由 MySQL 卡片发布及配对的不可变 Qdrant 节点和边 collection 构成。请求只固定完整三元组一次；每次结构化与向量读取都必须使用它。请求中混合修订或静默切换发布是无效行为。

MySQL 或签名发布工件是结构化规范内容的权威来源。Qdrant 是可重建投影。向量候选只有经过同一发布的权威补全后才可使用。

## 降级

向量检索不可用时，服务可返回带显式降级元数据的有用 MySQL 基础卡，但不得虚构关系或隐藏缺失知识族。权威结构化数据或发布兼容性失败时，操作必须安全失败。

发布状态只可通过离线工作流改变。实时请求不能创建别名、卡片、事实、领域、边、修订或发布。
