# 离线发布

English: [Offline publication](../../../docs/reference/operations/publication.md)

本模块负责将已审核内容转变为不可变兼容发布的离线路径。

## 工作流

Publisher 暂存结构化内容，校验 schema 与权利，检查证据和确定性不变量，写入权威修订，投影不可变向量节点与边 collection，核对精确计数与发布标识符，执行质量门禁并原子激活发布。隔离、移除与回滚保留可审计性与兼容性。

Publisher 是单独的组合根，也是唯一允许接收可变更结构化与向量 port 的组件。生成候选不是证据；只有配置的证据、权利、确定性校验与审核策略通过后才成为规范内容。

## 在线边界

实时翻译和查询请求绝不调用发布、创建持久提案，也不把文本或输出写入规范存储。请求级缺口与候选领域随请求消失；只有独立授权离线流程可刻意导入已审核材料。

操作命令、manifest、回滚规则与验证门禁由[内容发布指南](../../guides/content-publishing_cn.md)负责。
