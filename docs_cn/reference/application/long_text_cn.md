# 长文本翻译支持

English: [Long-text translation support](../../../docs/reference/application/long_text.md)

长文本 application 模块为无法作为一个有界 provider 输入处理的连续文本提供目标请求级规划。

状态：目标设计。当前运行时为超过配置的 4,000 字符路由阈值的输入选择 TranslateGemma，但目前未组合独立的分块规划器或术语台账模块。

## 职责

模块推导尊重段落、受保护区段与语义边界的有界分块计划。它维护名称、缩写、重复术语和已解析选择的术语台账，再合并译文分块且不改变顺序或丢失内容。

计划与台账是实现细节，不是线上字段或规范记录。模块向翻译路径返回连续文本聚合数据，不创建持久任务、队列、翻译记忆或可恢复的用户工作流。

## 依赖与不变量

分块翻译在请求的单一 deadline 与容错预算内使用翻译模型 port。所有分配均由请求拥有并在返回前释放；当前文本、分块、台账项和 provider body 绝不进入日志、指标、缓存、MySQL、Qdrant 或持久队列。

分块必须保留结构和全局术语一致性。已接受的历史数组在 body 与 deadline 边界内整体使用，不得由此模块静默截断。

## 验证

测试应覆盖边界安全拆分、受保护区段、段落重建、重复术语、名称与缩写、空或畸形 provider 分块、取消及总大小限制。隐私测试应证明计划与台账在成功和每条失败路径上都会消失。
