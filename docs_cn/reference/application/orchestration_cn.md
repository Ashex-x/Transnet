# 请求编排

English: [Request orchestration](../../../docs/reference/application/orchestration.md)

本模块负责传输校验之后、线上投影之前的一轮翻译。

## 流程

编排器接收已校验请求、请求 ID、一个 deadline 与一组兼容活动发布固定值。它将输入分类为单词、固定词汇短语或连续篇章，调用适用翻译或知识路径，构造一个超集结果，投影请求的响应级别，最后执行不变量校验。

调用方不选择模式、provider、领域、检索 filter、方言、语域或展示分区。这些都是有界内部决策。

## 不变量

所有规范与向量读取使用同一发布三元组。最小按时间排序历史可影响指代解析、术语连续性、词义排序与措辞，但不能改变规范身份或事实。文本、历史、中间输出和提案随请求丢弃。

编排器负责顺序与预算分配，不负责线上解析、provider 协议、存储查询或格式化。降级结果保持显式，绝不能用虚构事实填充。

## 验证

测试路由歧义、单一 deadline 传播、发布一致性、取消、依赖降级、响应级别单调性与请求状态丢弃。另见端到端[请求数据流](request-dataflow_cn.md)、[翻译](translation_cn.md)、[知识](knowledge_cn.md)和[服务接口](../../interfaces/transnet_cn.md)。
