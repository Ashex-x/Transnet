# 连续文本翻译

English: [Connected-text translation](../../../docs/reference/application/translation.md)

翻译 application 模块负责目标短连续文本翻译，并构建共享翻译聚合中的主要篇章部分。

状态：需要迁移当前行为的目标边界。当前运行时已通过过渡回环路由提供翻译，并将不超过配置路由阈值的文本发给 Gemma 4，但尚未通过此模块生成目标共享聚合。

## 职责

模块在生成自然目标语文本的同时保留含义、语气、语域、术语、段落结构、受保护区段、名称、数字、否定和相关格式。它可使用请求级历史解析指代，并保持术语、语气和后续指令连续。

译文始终是主要结果。只有存在实质歧义、习语、影响重大的语域选择或文化上下文时，才可附加至多两条单句提示；上下文不足时可包含一个明确标注的备选。详细词汇关系展开属于词汇路径。

## 依赖与不变量

模块在编排器 deadline 与 provider 容错边界内调用翻译模型 port 的连续文本操作。它接收已校验语言选择器，并返回 domain 翻译类型而非线上 envelope。

Provider 输出属于请求，除非另行从固定发布中解析出完全匹配的已审核译文，否则不具有规范性。实时流量绝不发布、缓存或标记译文重要。响应级别不能改变选定译文。

## 验证

测试应覆盖含义与完整性、结构、术语、名称、数字、否定、习语、方言、语气、格式、两条提示上限、无效 provider 输出、超时和有界 fallback。多 turn 用例应验证上下文使用及返回后的完整丢弃。
