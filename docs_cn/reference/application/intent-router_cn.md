# 意图路由器

English: [Intent router](../../../docs/reference/application/intent-router.md)

意图路由器是目标 application 边界：它把新 turn 分类为单词、固定词汇短语或连续篇章，并选择侵入性最低且有用的处理路径。调用方不提供 mode 开关。

状态：目标设计。当前运行时按文本长度路由普通翻译，并暴露单独的旧查询路径；尚未实现这一共享自动路由器。

## 职责

路由器使用当前文本、请求语言和请求级历史推导单元与意图。单词、术语、习语、短语动词或固定短语进入词汇及可能的领域处理；分句、句子或篇章进入连续文本翻译。含糊的短片段必须选择安全路径，保留有用翻译而不虚构词汇确定性。

结果是内部路由决策，不是新的公共请求字段。Provider 选择、领域选择、检索过滤器、方言、语域和格式仍由后续 application service 推导。

## 依赖与不变量

路由器可通过 application port 使用有界模型分类，但闭合决策由确定性校验负责。它不得调用存储变更操作或持久化输入。

历史可影响指代与意图，但绝不改变规范身份。路由独立于响应级别，因此 `brief`、`standard` 和 `full` 始终是同一选定工作流及超集的投影。

## 验证

测试应覆盖单词、专业术语、习语、短语、句子、篇章、`C++` 等符号、混合语言文本和含糊片段。评估应确认无需 WebUI mode、不会静默截断已接受历史，且路由错误不创建持久状态。
